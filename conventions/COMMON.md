# COMMON

- Stay within the user's authorized scope.
- Use **English** by default, including code, comments, identifiers, parameter names, filenames, technical terms, and `AGENTS.md`.
  - An explicit local language rule overrides these rules only for the files, folders, or conditions it specifies.
- Do not stage files unless explicitly requested or needed for a requested commit.
- Do not expose secrets or silently change credentials, permissions, agent models, agent reasoning settings, or service tiers.

## Files

- Name Docker Compose files `docker-compose.yml`.
