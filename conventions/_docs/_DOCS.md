# DOCS

Use these conventions when working with documentation. Treat wiki pages as documentation.

## Routing

| Action | Read |
| --- | --- |
| Write, edit, or review documentation | [WRITING](./WRITING.md) |
| Read, search, create, edit, move, or remove wiki pages | [WIKI](./WIKI.md) |
| Add, update or change document links | [LINKS](./LINKS.md) |
| Save, maintain, or transfer an idea | [IDEAS](./IDEAS.md) |
| Prepare a code commit, record an accepted task, or record significant verification | [DONE_JOURNAL](./DONE_JOURNAL.md) |
