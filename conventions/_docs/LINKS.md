# LINKS

## Format

- Write new internal document and file links as Markdown links relative to the source file, with an explicit `./` or `../` prefix where the link boundaries permit it. Keep `#heading` after the path when linking to a section.
- Use readable heading anchors without percent encoding; preserve non-Latin characters. Do not convert external URLs, email links, or same-page `#anchor` links into file paths.
- Preserve links in journal entries that do not belong to the current commit. See [DONE_JOURNAL](./DONE_JOURNAL.md#immutable-history).
