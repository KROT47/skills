# WRITING

## Names and structure

- For new or renamed project Markdown files, use uppercase Latin letters, digits, and underscores: `MY_DOCUMENT_2.md`.
- When updating headings, preserve existing file paths, symlink entry points, and tool-specific identifiers.
- Match the first H1 and optional frontmatter `title` to the filename without the extension, replacing underscores with spaces and preserving case (for example, `JS_TS_CODE_STYLE.md` → `JS TS CODE STYLE`). For a directory index, use the directory name in uppercase as the filename and heading, retaining its leading underscore only in the filename (for example, `_docs/_DOCS.md` has heading `DOCS`).
