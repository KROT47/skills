# Common conventions skill

For every task, read and follow the [common rules](./COMMON.md).

## Routing rules

- Before starting work, select every Action that applies to the task in each Routing table.
- Read the corresponding documents in the Read column; repeat the selection in any nested Routing table.
- Do not load branches that do not apply. If the task changes, follow any newly applicable routes.

## Routing

| Action | Read |
| --- | --- |
| Write, refactor, or review code; create, change, or document a CLI; configure environment variables or service ports; manage workarounds; update dependencies; or introduce a technology or service | [Development](./_development/_DEVELOPMENT.md) |
| Find, review, write, move, or remove documentation; add or change document links; save, maintain, or transfer an idea; prepare a code commit; or record an accepted task or significant verification | [Docs](./_docs/_DOCS.md) |
